# Academic Writing Standards

> Violating any hard rule → paper cannot be marked submission-ready.

## Hard Rules

### Structure
- [ ] Paper type determined (empirical/theoretical/method/survey)
- [ ] 5-8 section structure fits the paper type
- [ ] Abstract is self-contained: 1 sentence problem + 1 sentence method + 1 quantitative result + 1 sentence significance
- [ ] Introduction final paragraph explicitly answers: What, Why, So What

### Claims-Evidence Alignment
- [ ] Every quantitative/qualitative claim in the paper has a matching evidence entry in the Claims Matrix
- [ ] Every supported claim in the Claims Matrix has a corresponding paragraph in the paper
- [ ] No "orphan" paper claims (ones not in the Claims Matrix)
- [ ] Evidence strength matches wording: strong evidence → confident language, weak evidence → hedged language

### Figures & Tables
- [ ] Every figure has a clear take-away message (what conclusion should a reader draw from this figure)
- [ ] Figure 1 (hero figure) shows the core finding; a skim reader can understand the contribution from it
- [ ] All figures/tables derived from experiment data (no hand-drawn diagrams substituting for data plots)
- [ ] Every number in tables/figures traceable to a raw_record.json

### Citations
- [ ] Every citation has complete metadata in Zotero
- [ ] Citations cover all prior work from the comparison matrix
- [ ] Key claim-supporting citations are peer-reviewed versions (not arXiv preprints)
- [ ] No "ghost citations" (appearing only in bibliography but never cited in text)

### Writing Quality
- [ ] No hype words ("revolutionary", "first-ever", "breakthrough" unless ironclad evidence exists)
- [ ] Quantitative results have context ("85.3% accuracy" alongside baseline's "78.1%")
- [ ] Limitations section honestly discusses shortcomings (at least 3 specific limitations)
- [ ] No wall-of-text paragraphs (single paragraph > 15 lines → split)

### Review
- [ ] At least 1 round of Agent internal review completed (blank context)
- [ ] All MAJOR issues from review resolved
- [ ] Review score ≥ 6/10 or verdict = "accept"
